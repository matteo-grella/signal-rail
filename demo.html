Reference web demo of Signal Rail 1.0. The frame engine (rail.js) is a byte-verified port of the voice agent's rail.zig: every frame is a pure function of (state, entry tick, tick, width, quantized levels, seed). The sliders are the point — LISTENING amplitude, SPEAKING spawn rate, and ACTING progress come from your inputs, never from scripted activity: set input level to zero and listening goes still; check "progress unknown" and the percentage disappears instead of lying. Keys: [ / ] cycle states. WARNING is implemented from spec §25 (the voice agent omits it — no genuine warning source).
